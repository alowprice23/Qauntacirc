# Example: Basic Usage

This example demonstrates the basic workflow of creating a project, configuring it, and running it.

## 1. Project Configuration

After running `qc init`, you will have a `qc_config.yml` file. Here is a basic configuration:

```yaml
# qc_config.yml
project_name: "BasicExample"
description: "A basic example of a QuantaCirc project."

# The list of agents to load for this project.
# The system will look for these agents in the /agents directory.
agents:
  - name: "HelloWorldAgent"
    enabled: true

# Parameters for the convergence engine.
engine_params:
  max_steps: 1000
  tolerance: 1e-6
```

## 2. Agent Implementation

Here is the code for the `HelloWorldAgent` that was generated by `qc generate agent`.

```python
# agents/hello_world_agent.py
from agents.base.agent import BaseAgent
from core.types import State, Transition

class HelloWorldAgent(BaseAgent):
    """
    A simple agent that prints a message.
    """
    def propose_transition(self, state: State) -> Transition:
        """
        This agent doesn't propose any state changes, so it returns an empty transition.
        """
        print("HelloWorldAgent: Proposing a transition (doing nothing).")
        return Transition(operations=[])

    def execute_transition(self, transition: Transition) -> State:
        """
        This agent doesn't execute any transitions.
        """
        # In a real agent, you would modify the state here.
        return self.state
```

## 3. Running the Example

With the configuration and agent in place, you can run the project:

```bash
qc run
```

The output will show the `HelloWorldAgent` being loaded and participating in the simulation, even though it doesn't perform any actions. This demonstrates the basic structure of a project.
